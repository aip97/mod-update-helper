# 모드 위키 관리자

`dist/WML-Wiki-Admin.exe`를 실행해 관리자로 승인된 Supabase 이메일과 비밀번호로 로그인합니다. 신청 목록에서 내용을 수정·저장하거나 승인·반려하고, 공개된 모드도 수정할 수 있습니다. 서버의 게시글·ZIP 자동 수집과 자동 공개는 현재 중단되어 있으므로 모든 신청의 게시글, 파일, 호환성과 소유권을 관리자가 직접 확인해야 합니다. 카테고리는 WML 기본 분류를 선택하거나 기존 값을 유지·직접 입력할 수 있습니다.

관리자 등록과 서버 스키마가 준비돼야 실제 로그인과 심사를 사용할 수 있습니다. 프로그램은 공개 API 키와 로그인 사용자 토큰만 사용하며 비밀번호나 토큰을 파일에 저장하지 않습니다. 관리자 권한은 서버에서 확인합니다.

로그인 만료 시 세션을 자동 갱신합니다. 자동 갱신에 실패하면 작성 중인 내용을 유지한 채 상단의 **다시 로그인**을 눌러 비밀번호를 입력한 후 저장하세요.

개발 검증: `python -m unittest -v test_client.py`

빌드: `python -m PyInstaller --noconfirm --onefile --windowed --name WML-Wiki-Admin --add-data "config.json;." admin.py`
