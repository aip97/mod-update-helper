모드 업데이트, 처음 한 번만 설정하세요.

모드 업데이트 도우미 0.8.0 · Windows의 Chrome / Edge용

설치 그림은 0.7.0을 읽어 들인 Chrome 화면입니다. 모드 화면은 0.7.0 UI에 가상 모드·경로·백업을 넣은 사용 안내용 예시이며 실제 배포 버전이나 설치 결과가 아닙니다. Edge는 버튼 위치가 조금 다릅니다. 이 HTML 하나만 있어도 그림까지 볼 수 있습니다.

처음 설치모드 업데이트게임 본체막혔을 때

1사용자용 ZIP을 풀고 실행

Mod-Update-Helper-User-0.8.0.zip을 모두 압축 해제한 뒤 Install.cmd를 더블클릭하세요.

게임을 실행하는 브라우저를 고릅니다. 1 = Chrome, 2 = Edge. 도우미가 표시한 설치 폴더 경로를 기억해 주세요.

설치 과정에서 현재 Windows 사용자의 Chrome/Edge에 로컬 파일 연결 도우미를 등록합니다. 이후 게임 경로를 감지하면 기본으로 자동 연결합니다.

모더용(Modder) ZIP은 제작자를 위한 자료입니다. 일반 사용자는 User ZIP만 받으면 됩니다.

2개발자 모드를 켜고 폴더 불러오기

열린 확장 프로그램 화면에서 개발자 모드를 켜고 압축해제된 확장 프로그램 로드를 누르세요.

도우미가 알려 준 설치 폴더를 선택하세요. manifest.json이 들어 있는 폴더입니다.

화면이 안 열렸다면 주소창에 Chrome은 chrome://extensions, Edge는 edge://extensions를 입력하세요.

3파일 URL 접근 허용

모드 업데이트 도우미 → 세부정보를 열고 파일 URL에 대한 액세스 허용을 켜세요.

이 스위치가 켜져 있어야 내 컴퓨터의 게임을 읽을 수 있습니다.

4게임을 열고 활성 모드 찾기

평소처럼 WML 게임을 열고, 브라우저의 확장 프로그램 버튼 → 모드 업데이트 도우미를 누르세요. 이미 실행 중인 게임도 연결할 수 있습니다.

활성 모드 탭에서 한국어 이름·원래 이름·ID로 검색하세요. 한국어명은 모드 파일의 기존 번역을 우선하고 없으면 내장 명칭 사전을 사용합니다. 둘 다 없으면 원래 이름을 유지합니다. 게시글 주소가 없는 모드는 선택해서 모드 설정에서 제작자의 코네 게시글 주소를 저장하세요.

모드 설정에서 목록을 눌러 모드를 선택하고 이름·ID로 검색할 수 있습니다. 검색 결과가 없어도 현재 선택은 유지됩니다.

API 미지원이어도 주소를 직접 입력하면 됩니다. API가 주소를 제공하면 그 주소가 우선입니다.

5필요한 모드를 한 번에 업데이트

  1. 업데이트 필요 탭에서 최신 버전을 확인합니다.
  2. 업데이트할 모드를 선택하고 자동 연결된 게임 폴더를 확인하세요. 지금 실행한 게임 HTML과 wml 폴더가 함께 있는 곳입니다. 다른 폴더를 쓸 때만 경로 변경을 누릅니다. 다른 계열·버전의 HTML이나 WML 폴더를 선택하면 중단합니다. 이미지팩 동봉 모드도 함께 백업·업데이트합니다.
  3. 처음 업데이트할 때 기본 비밀번호를 입력합니다. 이 브라우저에 저장되어 다음 실행에도 사용하며 기본 비밀번호 설정·변경으로 바꿀 수 있습니다. 잠긴 컬렉션은 파일 목록 확인에도 비밀번호가 필요합니다. 미리 정해 둔 비밀번호는 없으며, 저장값 하나를 모든 모드와 게임 본체가 공통으로 사용합니다. 미설정이면 도우미를 열 때 빈 설정창이 나타납니다. 모드와 버전을 확인하고 승인하면 순서대로 설치됩니다.
  4. 완료되면 게임 진행을 저장한 뒤 게임을 새로고침하세요.

게임 실행 시 새 버전이 발견되면 업데이트 화면이 열립니다. 설치는 승인 후 진행합니다. 버전 없는 ZIP은 상태 확인 중 읽어 내부 버전을 검사합니다.

모드와 게임 본체 ZIP은 설치 전에 Windows Microsoft Defender로 검사합니다. 위협이 발견되거나 검사를 완료할 수 없으면 설치가 중단됩니다. 0.7.3 이상의 Windows 로컬 연결 도우미가 필요합니다. 검사가 모든 악성 파일의 탐지나 파일의 안전성을 보장하지는 않습니다.

모드 위키는 사전 검증용입니다.

Supabase 데이터베이스와 등록 함수의 배포 및 실제 연동 검증이 완료되어야 사용할 수 있습니다. 서버가 준비되면 모드 위키 탭에서 승인된 모드를 찾을 수 있습니다. 게시글 추천은 코네에 로그인한 뒤 게시글에서 직접 누르세요.

등록 또는 수정 신청 시 대상 게임(일반 Wayward, Faith, Overtime, 공용 또는 기타), 지원하는 버전, 게시글, 호환 조건, 설명과 카테고리를 입력하고 게시글·Kio 파일·ZIP과 Defender 검사를 통과해야 합니다. 모드 API 자동 신청은 명시적으로 동의한 경우에만 진행하며 Kio 비밀번호와 게임 저장 데이터는 보내지 않습니다. 서버의 코네 인증 연동이 완성되기 전에는 게시글과 ZIP을 자동 수집하지 않으며, 모든 신청을 관리자가 직접 검토하므로 자동 공개되지 않습니다.

새 모드 설치는 게시글과 ZIP을 다시 검사하고 확인을 받은 뒤 진행합니다. 설치가 끝나면 게임을 닫고 wml/mods/update-mod-list.cmd 또는 wml/mods/모드목록_자동갱신.cmd를 직접 실행한 뒤 게임을 다시 여세요.

게임 본체도 업데이트할 수 있습니다.

제작자가 게임 업데이트 API를 제공한 게임과 기본 연결된 Faith·Overtime 배포 글에서 새 버전을 찾습니다. 기존 모드 사용법은 그대로입니다.

  1. 게임 게시글 진단으로 링크와 ZIP 이름을 검사할 수 있습니다. 파일명에 버전이 없거나 규칙이 다르면 수정할 이름·다운로드 컬렉션·HTML 예상 위치를 안내합니다. 게임 본체 탭에서 전체판·경량판을 선택하고 새 버전을 확인합니다. 처음 정한 배포판은 이 브라우저에 기억합니다.
  2. 다운로드·검사를 누릅니다. ZIP과 HTML 버전을 검사한 뒤 설치 내용을 보여 줍니다.
  3. 게임을 저장하고, 다른 브라우저의 게임과 이미지 서버를 종료하세요. 저장 완료에 체크한 뒤 저장했습니다. 게임 닫고 설치를 누릅니다.
  4. 현재 브라우저의 해당 게임 폴더 HTML 탭을 닫고 백업·설치합니다. 도우미 창은 열어 두세요. 완료 후 게임 다시 열기를 누릅니다.

실행하던 HTML 파일명, 세이브·설정·설치 모드·프리셋·이미지팩·생성 이미지를 보존합니다. 게임 자체의 정적 이미지와 프로그램 파일은 바뀔 수 있습니다. 본체 업데이트로 설치된 모드와 호환성 충돌이 발생할 수 있습니다. 설치 확인창의 안내를 확인하세요.

본체 설치는 실행 중인 게임의 실제 경로를 사용하며 Windows 로컬 도우미가 필요합니다. 모드용 경로 변경과 별개입니다. 본체 백업은 .wml-game-updater-backups/에 저장됩니다. 일반 설치 오류나 도우미 창 연결 종료는 복구하지만, 전원 차단·프로세스 강제 종료의 자동 복구는 보장하지 않습니다.

막혔을 때는 여기만 확인하세요.

활성 모드가 보이지 않아요.

게임과 확장이 같은 브라우저에 있는지 확인하세요. 3번의 파일 URL 접근을 켠 뒤, 게임 탭을 열어 둔 상태에서 확장의 목록 새로고침을 누르세요. 다른 브라우저 프로필의 게임은 연결되지 않습니다.

코네 로그인이 필요하다고 나와요.

같은 브라우저에서 안내된 게시글을 열어 로그인한 뒤 다시 확인하세요. Kio 공유 비밀번호와 코네 로그인은 서로 다릅니다. 로그인·인증·열람 제한은 게시글 형식 오류와 구분해 안내합니다. 공개 본문을 읽을 수 있으면 로그인 없이도 진단합니다.

게시글 주소를 넣었는데 업데이트가 안 떠요.

모드 설정에서 게시글 진단을 누르세요. 제목은 자유 형식입니다. 본문 공유 링크와 컬렉션의 모드 파일명을 확인하세요. 수정이 필요한 부분은 진단 결과를 제작자에게 전달하세요.

ZIP 안에 wml/mods 폴더가 없어도 되나요?

0.5.1부터 mod.js가 ZIP 바로 안에 있거나 지원하는 모드 폴더 구조에 있어도 인식합니다. 도우미가 선택한 모드 폴더로 맞춰 적용하므로 직접 옮길 필요가 없습니다. 여러 모드가 섞였거나 ID·버전이 다르면 중단합니다.

게임 폴더가 자동 연결되지 않아요.

User ZIP의 Install.cmd로 로컬 연결 도우미까지 설치했는지 확인하세요. 도우미가 없거나 로컬 드라이브가 아닌 경로라면 경로 변경에서 폴더 접근을 허용할 수 있습니다. 이 수동 경로는 별도로 기억하며, 브라우저 권한이 만료되면 다시 허용해야 합니다. 자동 연결만으로 모드를 설치하지는 않습니다.

Faith나 다른 비슷한 게임도 사용할 수 있나요?

같은 WML 구조와 게임 식별 규약을 쓰면 계열 이름을 새로 등록하지 않아도 인식합니다. WML은 0.9.3 이상이어야 하며 모드의 지원 게임·WML 조건은 따로 검사합니다. 모드는 제작자가 해당 게임을 지원하는 ZIP을 제공해야 합니다. 게임 전체 ZIP은 별도의 게임 본체 업데이트 절차로 설치합니다. Faith·Overtime은 기존 배포 글이 기본 연결되어 있어 게임 코드를 수정하지 않아도 됩니다.

WML 버전이 맞지 않는다고 나와요.

다운로드한 모드가 현재 WML을 지원하지 않으면 설치를 중단합니다. 지원 선언이 없으면 ‘호환성 미확인’으로 표시하고 한 번 더 확인받습니다.

모드를 업데이트 전으로 되돌리고 싶어요.

활성 모드 → 대상 모드의 롤백 → 게임 폴더 연결 → 업데이트 전 백업 선택 → 승인 순서로 진행하세요. 검증 가능한 해당 모드와 동봉 이미지팩의 백업만 복원하며 현재 파일도 먼저 보호 백업합니다. 게임 계열·실행한 HTML·WML 호환성이 맞지 않으면 중단합니다. 완료 후 게임을 새로고침하세요. 게임 세이브를 과거로 되돌리는 기능은 아니며 전원 중단 때 자동 복원을 보장하지 않습니다.

도우미 자체는 어떻게 업데이트하나요?

도우미 화면 상단에서 현재 버전과 업데이트 상태를 확인할 수 있습니다. 브라우저 시작 시와 주기적으로 새 버전을 확인하고, 연결된 게임을 시작할 때도 한 번 확인합니다. 기다리지 않고 확인하려면 도우미 업데이트 확인 버튼을 누르세요. 새 버전 알림이 나타나면 진행 중인 작업을 마친 뒤 도우미 업데이트 후 재시작을 누르세요. 다른 도우미 창이 열려 있으면 해당 창의 작업을 마치고 닫은 뒤 다시 시도하세요. 자동 확인은 새 버전을 알리며 설치는 업데이트 후 재시작 버튼으로 진행합니다. 게임은 자동 새로고침하지 않습니다. 0.7.3 이상의 도우미가 다음 버전으로 업데이트할 때는 서명과 ZIP 해시 확인 후 Microsoft Defender로 검사하며, 위협이 발견되거나 검사를 완료할 수 없으면 적용하지 않습니다. 0.7.2 이하에서 0.7.3으로 업데이트할 때와 최초 설치에는 이 자동 검사가 적용되지 않습니다. 저장소가 없는 개발 사본은 자동 업데이트 준비 중으로 표시합니다. 새 버전의 시작 확인이 없으면 이전 파일로 복구하며 브라우저가 확장을 비활성화한 경우 직접 다시 불러와야 할 수 있습니다.

설치 도우미는 확장과 로컬 연결 도우미를 설치합니다. 모드 파일 변경은 게임 폴더를 연결하고 승인한 뒤 진행됩니다.
