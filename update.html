        적용할 게임 폴더

        인식된 게임 경로에 자동 연결합니다. 다른 위치는 경로 변경으로 지정해 주세요.

        자동 연결에는 0.6.0 설치 도우미가 필요합니다. 연결과 검사만으로는 파일을 변경하지 않습니다.

        선택 모드 롤백

        업데이트 전 버전을 골라 이 모드만 되돌립니다. 현재 파일도 별도 백업합니다. 게임을 저장하고, 롤백 완료 후 새로고침해 주세요.

          배포 게시글

          모드를 선택해 주세요.

          현재 입력한 주소의 작성 형식을 진단합니다. 주소 저장과 설치는 하지 않습니다. 파일명에 버전이 없으면 ZIP을 읽어 내부 헤더도 확인합니다.

          게시글 링크와 Kio 파일명을 확인합니다. 버전 없는 파일은 ZIP 헤더도 읽습니다. 설치 전 전체 구조·호환성을 다시 검사합니다.

          게시글 작성 형식과 예시
          

          게시글 제목은 자유롭게 작성할 수 있습니다.
          본문에 Kio 컬렉션 링크 또는 Base64 링크를 넣으세요. 컬렉션 하나에 여러 모드와 이전 버전을 함께 올려도 됩니다.
          ZIP 이름은 <mod-id> 1.2.3.zip으로 맞추세요. 해당 ID의 가장 높은 버전을 선택하며 같은 최신 버전 파일이 중복되면 중단합니다. 설치 전 내부 ID·버전과 게임 호환성을 다시 검사합니다.
          GameFolder\\wml\\mods\\<id>\\ 같은 포장 폴더와 역슬래시도 지원합니다. 함께 든 image-packs/ 파일도 백업·업데이트·롤백에 포함합니다.
          설치·사용 안내
          처음 업데이트할 때 기본 비밀번호를 입력합니다. 이 브라우저에 저장되어 다음 실행에도 사용합니다. 여기서 바꾼 모드별 값은 현재 창에서만 적용됩니다.
          

          자동 다운로드가 막히면 공유 페이지에서 모드 ZIP을 직접 내려받아 선택할 수 있습니다. 선택 후 업데이트 여부를 다시 확인합니다.
          

          사용 안내
          WML에서 폴더 모드를 사용해야 합니다. 브라우저에 설치한 모드 복사본이 있으면 폴더 업데이트보다 우선할 수 있습니다. 버전이 다르면 적용을 막지만, 같은 버전의 브라우저 복사본은 감지하지 못합니다. 해당 복사본을 해제한 뒤 이용해 주세요.
          ‘업데이트’를 확인하면 모드 ZIP을 내려받아 검사하고, 변경할 기존 파일을 게임 폴더 안에 백업한 다음 적용합니다. 이미지 서버 ZIP은 자동 적용하지 않습니다. 게임을 저장한 뒤 업데이트하고, 완료 후 새로고침해 주세요.
          이 도우미는 선택한 폴더에 대한 브라우저 쓰기 권한을 사용합니다. Chrome 또는 Edge 최신 버전을 이용해 주세요.
          

          업데이트할까요?
          게임을 먼저 저장해 주세요. 선택한 모드의 기존 파일은 백업 후 교체됩니다.
          다운로드 기본 비밀번호
          입력한 값은 이 브라우저에 저장하고 다음 업데이트에도 사용합니다. 비밀번호가 없는 공유는 빈칸으로 저장하세요. 잠긴 컬렉션은 파일 목록 확인에도 비밀번호가 필요합니다.
          게임을 저장하고 설치할까요?
          현재 브라우저에서 확인한 게임 폴더의 HTML 탭을 닫고 자동 설치합니다. 다른 브라우저의 게임과 이미지 서버도 먼저 종료해 주세요. 설치 중에는 이 도우미 창을 열어 두세요.
